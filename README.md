## 구현할 기능 목록

숫자 맞추기 게임을 야구처럼 해보기!

구현할 기능 목록

3가지 숫자를 컴퓨터가 임의로 제시하면 세 숫자를 맞춰서 이기면 성공!

1) 볼(숫자는 맞았지만 위치가 틀린 경우)
2) 스트라이크(숫자와 위치 모두 맞는 경우)
3) 낫싱(세 숫자 모두 숫자와 위치가 모두 틀린 경우)
4) 3스트라이크에 성공하면 게임을 다시 할 것인지 묻고 사용자 선택에 따라 게임 재시작 가능!

게임은 3스트라이크가 이루어지기 전까지 계속 진행되며 사용자가 입력할 떄 마다 현재 볼과 스트라이크 수를 알려줌으로써 힌트 유추 가능!
